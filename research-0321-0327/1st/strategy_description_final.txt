  네트워크 기반 적응형 포트폴리오 전략 — 최종 버전
  Network Centrality Portfolio with Z-Score Composite
═══════════════════════════════════════════════════════════════════════════

■ 전략 한 문장 요약

  주식 간 상관관계를 네트워크로 모델링하고,
  시장의 관심 밖에 있지만 구조적으로 의미 있는 위치의 종목을
  체계적으로 찾아 투자하는 전략.


■ 전략 원리

  주식시장에서 투자자들의 관심은 네트워크 중심부에 집중된다.
  삼성전자에 애널리스트 100명이 붙지만 주변부 종목은 0~1명이다.
  이 관심의 불균형이 가격의 불균형을 만든다.

    중심부: 관심 많음 → 가격 효율적 → 적정가 → 초과수익 없음
    주변부: 관심 없음 → 가격 비효율적 → 저평가 → 초과수익 발생

  이 저평가는 뉴스 한 건으로 사라지는 것이 아니라,
  누군가 주목할 때까지 수개월간 지속된다.
  Merton(1987)의 Investor Recognition Hypothesis에 따르면,
  투자자 인지도가 낮은 종목은 더 높은 기대수익률을 요구받으며,
  이 프리미엄은 정보 속도가 빨라져도 사라지지 않는다.

  저평가 해소는 세 가지 경로로 발생한다:
    1. 촉매(Catalyst): 실적 발표, 수주 공시, 커버리지 시작
    2. 평균 회귀: 펀더멘탈 대비 싸면 시간이 지나며 적정가로 수렴
    3. 네트워크 전파: 같은 클러스터의 다른 종목이 주목받으면 연관 종목도 관심 유입

  300개 종목을 분산 보유하면 매월 일부에서 촉매가 발생하여
  평균적으로 초과수익이 꾸준히 발생한다.

═══════════════════════════════════════════════════════════════════════════
  STEP 3. 상관행렬 구성 및 노이즈 제거 (Marchenko-Pastur Clipping)
═══════════════════════════════════════════════════════════════════════════

  (a) 상관행렬 계산
      - 전월말 기준 직전 60거래일의 일별 수익률 사용 (수정주가 기준)
      - 결측치가 80% 이상인 종목은 제외
      - 등가중 상관행렬 C 계산

  (b) Marchenko-Pastur Clipping
      랜덤 행렬 이론(RMT)에 기반하여 상관행렬의 노이즈를 제거한다.

      1) 상관행렬의 고유값 분해: C = V Λ V^T
      2) 랜덤 행렬 고유값 상한 계산: λ_max = (1 + √(N/T))²
         여기서 N = 종목 수, T = 관측 기간(60일)
      3) λ_max 이하의 고유값은 노이즈로 간주 → 평균값으로 대체
      4) 전체 고유값의 합이 N이 되도록 스케일링
      5) 클리핑된 고유값으로 상관행렬 재구성

      결과: 시그널 고유값만 보존된 "정화된" 상관행렬

      학술 근거:
      - Marchenko & Pastur (1967) — 랜덤 행렬 고유값 분포
      - Laloux et al. (1999) — 금융 상관행렬에의 적용


═══════════════════════════════════════════════════════════════════════════
  STEP 4. 네트워크 구성
═══════════════════════════════════════════════════════════════════════════

  (a) 인접행렬 생성
      - 클리핑된 상관행렬에서 음의 상관관계는 0으로 처리
      - 대각원소는 0으로 설정 (자기 자신과의 연결 제거)
      - A_ij = max(C_clipped_ij, 0), A_ii = 0
      - 바이너리(0/1)가 아닌 가중 인접행렬: 상관계수의 크기가 연결 강도

  (b) 네트워크 해석
      양의 상관관계가 높은 종목 쌍 = 강한 연결
      → 시장에서 비슷하게 움직이는 종목군(클러스터) 파악


═══════════════════════════════════════════════════════════════════════════
  STEP 5. 파라미터 도출 (모두 데이터에서 도출, 고정값 0개)
═══════════════════════════════════════════════════════════════════════════

  5-1. β (Cap-Scaled Centrality 페널티 강도)
  ─────────────────────────────────────────
  목적: 대형주의 centrality를 적절히 억제하기 위한 페널티 강도

  도출 과정:
    1) 일반 eigenvector centrality 계산: A·x = λ·x
    2) log(centrality) vs log(시총) 회귀분석
    3) β = |기울기| / 2

  의미: 시총과 centrality의 관계 강도의 절반만큼 페널티
       → 완전히 제거하면 과보정, 절반만 제거하여 균형

  평균값: β ≈ 0.215 (월별로 변동)

  5-2. w (λ₁ Loading 가중치)
  ─────────────────────────────────────────
  목적: composite score에서 시장팩터(λ₁) 오염을 얼마나 제거할지

  도출: w = √(λ₂/λ₁)

  의미: 제2고유값과 제1고유값의 비율의 제곱근
       λ₁이 지배적일수록 w↓ → 시장팩터 제거를 덜 함
       λ₂가 상대적으로 클수록 w↑ → 시장팩터 제거를 더 함

  학술 근거: Plerou et al. (2002) — 금융 상관행렬의 고유값 구조

  평균값: w ≈ 0.474

  5-3. cutoff (시총 상위 제외 비율)
  ─────────────────────────────────────────
  목적: 시장팩터(λ₁)에 오염된 대형주를 투자 대상에서 제외

  도출: cutoff = √(λ₁ / tr(Λ)) = √(λ₁ / N)

  의미:
    - λ₁/N = Absorption Ratio (Kritzman et al., 2011)
      = 시장팩터가 전체 분산에서 차지하는 비율
    - Centrality는 고유값의 제곱근에 비례하므로 √(AR) 사용
    - 시장 위기 시 λ₁↑ → cutoff↑ → 더 많은 대형주 제외 (적응형)

  학술 근거:
    - Kritzman et al. (2011) — "Principal Components as a Measure of
      Systemic Risk"

  평균값: cutoff ≈ 0.384 (시총 상위 약 38% 제외)


═══════════════════════════════════════════════════════════════════════════
  STEP 6. 종목 스코어링 및 퀀타일 구성 (Z-Score 방식)
═══════════════════════════════════════════════════════════════════════════

  6-1. Cap-Scaled Eigenvector Centrality
  ─────────────────────────────────────────
  일반 centrality에 시총 페널티를 적용:

    x_new = diag(1/mcap^β) × A × x_old

  → 대형주: mcap↑ → 페널티↑ → centrality 억제
  → 소형주: mcap↓ → 페널티↓ → centrality 확대

  Power iteration으로 수렴할 때까지 반복 (최대 300회, tolerance 1e-8)

  학술 근거:
    - Bonacich (1972) — eigenvector centrality
    - Newman (2004) — 가중 네트워크 노드 속성 반영

  6-2. Z-Score Composite Score
  ─────────────────────────────────────────
  기존 rank 방식의 문제:
    rank는 0~N 범위라서 한 항이 다른 항을 지배할 수 있음

  Z-Score 방식:
    centrality_z = (centrality - mean) / std
    λ₁_z = (λ₁_loading - mean) / std

    composite_score = centrality_z - w × λ₁_z

  → 두 항이 평균 0, 표준편차 1로 표준화되어 균형 있게 작용
  → w가 진정한 가중치 역할을 수행

  해석:
    - 높은 score = centrality는 높지만 시장팩터 노출은 낮음
    - 즉, "네트워크에서 의미 있는 위치에 있되, 시장 전체와는
      독립적으로 움직이는 종목"

  rank → z-score 변경 효과:
    CAGR: 19.52% → 21.95% (+2.43%p)
    Sharpe: 0.81 → 0.90
    α t-stat: 5.37 → 6.03

  6-3. 투자 유니버스 필터링
  ─────────────────────────────────────────
    투자 유니버스 = 전체 종목 (네트워크 계산에는 모두 참여)
    투자 직전 필터:
      - 거래대금 하위 10% 제거 (유동성 필터)
      - 시총 상위 cutoff% 제거 (시장팩터 오염 제거)
      - 거래정지 종목 제거 (월초가격 == 월말가격)
      - 스팩(SPAC) 종목 제거
      - 주가 1,000원 미만 동전주 제거

    ※ 필터는 "네트워크 계산 후, 투자 직전"에 적용
       네트워크 구조 파악에는 모든 종목이 필요하므로

  6-4. 퀀타일 구성
  ─────────────────────────────────────────
    필터링된 종목을 composite_score 기준으로 5분위로 나눔:
    - Q1 (하위): score 낮은 종목 (네트워크 중심부, 시장과 동조)
    - Q5 (상위): score 높은 종목 (네트워크 주변부, 독립적 움직임)

    Q5에 투자.

  6-5. ScorePow 가중
  ─────────────────────────────────────────
    Q5 내에서 score 기반 비선형 가중:
      weights = (score - min + ε)^1.5
      weights /= sum(weights)

    → score가 높은 종목에 비중 집중
    → 등가중 대비 시그널 강도 반영


═══════════════════════════════════════════════════════════════════════════
  STEP 7. 거래비용 처리 (Amihud 차등비용, NAV 기반)
═══════════════════════════════════════════════════════════════════════════

  7-1. Amihud Illiquidity 계산
  ─────────────────────────────────────────
    ILLIQ_i = mean(|일별수익률_i| / 일별거래대금_i)  (월별 평균)

    학술 근거: Amihud (2002) — "Illiquidity and stock returns"

  7-2. 차등 비용률
  ─────────────────────────────────────────
    - Amihud 상위 20% (비유동 종목): 80bp (0.8%)
    - 나머지 (유동 종목): 30bp (0.3%)

  7-3. NAV 기반 거래비용 반영
  ─────────────────────────────────────────
  매월 리밸런싱 시:

    1) 목표 비중(target_weights)과 이전 비중(prev_weights) 차이 계산
       delta_w = target_w - prev_w

    2) 종목별 거래금액 계산
       trade_amounts = |delta_w| × NAV

    3) 종목별 비용률 적용
       cost_rate = 80bp (if illiquid) or 30bp (if liquid)

    4) 총 거래비용
       trade_cost = Σ(trade_amounts × cost_rate)

    5) NAV 갱신
       NAV_after_cost = NAV - trade_cost
       current_portfolio = target_weights × NAV_after_cost

    6) 수익률 반영 후 최종 NAV
       next_portfolio = current_portfolio × (1 + 월간수익률)
       NAV_new = Σ(next_portfolio)

    → 비용이 복리로 NAV에 반영되므로 가장 현실적인 방식

═══════════════════════════════════════════════════════════════════════════
  STEP 9. 성과 평가
═══════════════════════════════════════════════════════════════════════════

  9-1. 기본 지표
  ─────────────────────────────────────────
    - CAGR: 연평균 복리 수익률
    - Vol: 월간 수익률 표준편차 × √12
    - Sharpe: (월간초과수익률 평균 / 표준편차) × √12, rf=2%
    - MDD: 최대 낙폭 (고점 대비 최대 하락)

  9-2. Carhart 4-Factor Alpha (HAC)
  ─────────────────────────────────────────
    R_p - R_f = α + β₁·MKT + β₂·SMB + β₃·HML + β₄·MOM + ε

    - HAC (Newey-West) 표준오차 사용: 이분산성 + 자기상관 보정
    - α: 팩터 통제 후 초과수익 (연율화)
    - t-stat: α의 통계적 유의성
    - ***=1% 유의, **=5% 유의, *=10% 유의

    학술 근거: Carhart (1997) — "On Persistence in Mutual Fund Performance"

  9-3. 단조성 검정
  ─────────────────────────────────────────
    Q1 < Q2 < Q3 < Q4 < Q5 (CAGR 기준)
    → 시그널의 단조적 예측력 확인
    → 단순히 Q5가 좋은 게 아니라, 점진적으로 좋아져야 신뢰성 있는 시그널

  9-4. 5×5 이중정렬 (Double Sort)
  ─────────────────────────────────────────
    시총 5분위 × Composite Score 5분위 = 25개 포트폴리오
    → 시그널 효과가 특정 사이즈에 국한되지 않는지 확인
    → 같은 시총 내에서도 score가 높을수록 CAGR 증가 확인
    → "소형주 효과가 아니라 네트워크 시그널 효과" 증명

    학술 근거: Fama & French (1993)

  소형주 효과가 아닌 이유
═══════════════════════════════════════════════════════════════════════════

  1. Carhart 4-Factor에서 SMB 통제 후에도 α=14.55%(t=6.03***) 유의
     → SMB 팩터가 소형주 효과를 이미 흡수, α는 그 이후 남는 독립적 초과수익

  2. 5×5 이중정렬에서 같은 시총 내에서도 Score 단조 증가
     S1(소형): C1=21.2% → C5=36.2%
     S3(중형): C1=-2.1% → C5=20.8%
     S5(대형): C1=-9.3% → C5=6.5%
     → 시총을 고정해도 네트워크 시그널 작동

  3. Size-Neutral 포트폴리오에서도 α=7.42%(t=4.08***) 유의
     → 각 시총 그룹 내에서 score 상위를 뽑아도 초과수익 존재

  가격 지연(리드-래그)과의 관계
═══════════════════════════════════════════════════════════════════════════

  본 전략은 가격 지연을 이용하는 전략이 아니다.

  직접 검증:
    - 대형주-소형주 6만 쌍의 cross-correlation 분석
    - 평균 래그 5.5일 확인
    - 래그를 활용한 일간 트레이딩: CAGR 6% → 거래비용에 수익 소멸

  가격지연과 네트워크 mispricing의 차이:
    - 가격지연: 정보가 시차를 두고 반영 → 래그 끝나면 끝 (일시적)
    - 네트워크 mispricing: 관심 부족으로 구조적 저평가 → 수개월 지속

  증거:
    래그가 5.5일이면, 정보지연 전략의 수익은 6일 이후 0이어야 한다.
    그러나 본 전략은 20일, 40일, 60일 보유에서도 초과수익 유지.
    → 래그와 무관한 수익 원천 (구조적 저평가)

  학술 근거:
    - Hou & Moskowitz (2005) — 가격지연은 1주일 내 소멸
    - Merton (1987) — Investor Recognition Hypothesis
